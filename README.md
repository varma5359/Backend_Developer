## Authoring conventions

Each completed day has:
- A class-notes manuscript with worked examples, commands, explanations and the approved mini-project.
- A separate interview guide with answers, scenarios and follow-up questions.
- Five daily MCQs in the class notes.
- An AI-assisted implementation guide.
- A completion checklist.

Use the approved roadmap for exact syllabus titles and project names. Do not treat an index entry as proof that a future lesson has been written.
